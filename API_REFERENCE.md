# API Reference

This document details all available API endpoints, their expected JSON request parameters, and the resulting JSON responses.

---

## 1. Public Endpoints (No Authentication Required)

### 1.1 User Signup
Registers a new user and returns an authentication session.

- **Endpoint**: `POST /api/v1/auth/signup`
- **Request Body**:
  ```json
  {
    "email": "user@example.com",     // string, required, must be valid email
    "password": "mySecurePassword123" // string, required, length 8-128 chars
  }
  ```
- **Success Response (201 Created)**: Returns an [AuthResponse](#authresponse-object).

### 1.2 User Login
Authenticates an existing user and returns an authentication session.

- **Endpoint**: `POST /api/v1/auth/login`
- **Request Body**:
  ```json
  {
    "email": "user@example.com", // string, required, must be valid email
    "password": "mySecurePassword123" // string, required
  }
  ```
- **Success Response (200 OK)**: Returns an [AuthResponse](#authresponse-object).

### 1.3 Refresh Token
Generates a new short-lived access token (and a new refresh token) using a valid refresh token.

- **Endpoint**: `POST /api/v1/auth/refresh`
- **Request Body**:
  ```json
  {
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5c..." // string, required
  }
  ```
- **Success Response (200 OK)**: Returns an [AuthResponse](#authresponse-object).

### 1.4 Verify Email
Verifies a user's email address using a token (usually sent via email).

- **Endpoint**: `POST /api/v1/auth/verify-email`
- **Request Body**:
  ```json
  {
    "token": "a1b2c3d4e5f6g7h8..." // string, required
  }
  ```
- **Success Response (200 OK)**:
  ```json
  {
    "message": "email verified successfully"
  }
  ```

### 1.5 Forgot Password
Requests a password reset link for a given email. (Always returns success even if the email doesn't exist, to prevent email enumeration attacks).

- **Endpoint**: `POST /api/v1/auth/forgot-password`
- **Request Body**:
  ```json
  {
    "email": "user@example.com" // string, required, must be valid email
  }
  ```
- **Success Response (200 OK)**:
  ```json
  {
    "message": "if the email exists, a password reset link has been sent"
  }
  ```

### 1.6 Reset Password
Resets the user's password using the token generated by the Forgot Password flow.

- **Endpoint**: `POST /api/v1/auth/reset-password`
- **Request Body**:
  ```json
  {
    "token": "a1b2c3d4e5f6g7h8...", // string, required
    "password": "newSecurePassword!" // string, required, length 8-128 chars
  }
  ```
- **Success Response (200 OK)**:
  ```json
  {
    "message": "password reset successfully"
  }
  ```

## 2. Protected Endpoints (Requires Access Token)

**Important**: For all protected routes, you must pass the Access Token in the `Authorization` header:
`Authorization: Bearer <your_access_token>`

### 2.1 Get Current User
Retrieves the profile information for the currently authenticated user.

- **Endpoint**: `GET /api/v1/auth/me`
- **Request Body**: None
- **Success Response (200 OK)**: Returns a [UserResponse](#userresponse-object).

### 2.2 Logout
Revokes the provided refresh token so it can no longer be used.

- **Endpoint**: `POST /api/v1/auth/logout`
- **Request Body**:
  ```json
  {
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5c..." // string, required
  }
  ```
- **Success Response (200 OK)**:
  ```json
  {
    "message": "logged out successfully"
  }
  ```

## 3. Shared Response Objects

### AuthResponse Object
Returned when a user successfully signs up, logs in, or refreshes a token.
```json
{
  "user": {
    "id": "123e4567-e89b-12d3-a456-426614174000",
    "email": "user@example.com",
    "email_verified": false,
    "created_at": "2026-08-20T10:00:00Z"
  },
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5c...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5c...",
  "token_type": "Bearer",
  "expires_in": 900 // Token expiry in seconds (e.g., 900 = 15 minutes)
}
```

### UserResponse Object
Returned when fetching user profile data (does not expose sensitive data like password hashes).
```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "email": "user@example.com",
  "email_verified": false,
  "created_at": "2026-08-20T10:00:00Z"
}
```
